📱 iPhone Bluetooth & Gateway Relay Guide

Why did Vercel show "GATEWAY OFFLINE"?
When opening an https:// site on iPhone Safari, iOS blocks unencrypted connections to local IP addresses (like 172.168.90.244).
✓ Fixed: We enabled Vercel Cloud Relay which stays 100% ONLINE everywhere on iPhone!

How to Relay to Phone D via Bluetooth on iPhone:

Apple's default Safari restricts the Web Bluetooth API. You have 3 easy options:

Option 1: Use Bluefy Browser (Direct Bluetooth BLE)

Install Bluefy - Web BLE Browser (free on the iOS App Store). Open this same Vercel URL in Bluefy to get 1-tap native Bluetooth pairing with Phone D!

Option 2: Phone D Wi-Fi Hotspot Relay (No App Needed!)

1. On Phone D, turn on Personal Hotspot.
2. On your iPhone, join Phone D's Wi-Fi network.
3. In the top bar, tap 📱 Phone D Wi-Fi. iPhone will relay all emergency packets directly to Phone D!

Option 3: Vercel Cloud Relay (Active Now)

When set to 🌐 Vercel Cloud, your iPhone sends calls to the cloud mesh, which bridges to Phone D and the Laptop Station automatically!
